# TextTools Pro

Welcome to **TextTools Pro**, a versatile web application designed to enhance your text editing and programming calculation needs. This project is built with React and styled using Tailwind CSS, offering a seamless experience across both light and dark modes.

## Features

- **Text Editor**: 
  - Perform various text operations like removing extra spaces, formatting JSON, and more.
  - Supports light and dark themes for better readability.
  - Responsive design for all devices.

- **Programming Calculator**:
  - Convert text to binary and vice versa.
  - Intuitive UI with a focus on usability.
  - Consistent theme support with the text editor.

- **Theme Support**:
  - Automatic theme detection based on system settings.
  - Manual theme toggle for user preference.
  - Smooth transitions between light and dark modes.

- **Progressive Web App (PWA)**:
  - Installable on devices for a native app-like experience.
  - Offline support with service workers.

## Installation

To get started with TextTools Pro, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/yourusername/texttools-pro.git
   cd texttools-pro
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm start
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```

## Usage

- **Text Editor**: Navigate to the home page to access the text editor. Use the provided buttons to perform various text operations.
- **Programming Calculator**: Go to the `/calculator` route to use the programming calculator. Select the conversion mode and input your data.

## Technologies Used

- **React**: For building the user interface.
- **Tailwind CSS**: For styling the application.
- **React Router**: For navigation and routing.
- **Service Workers**: For offline support and PWA features.
